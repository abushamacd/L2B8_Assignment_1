# TypeScript Assignment of Programming Hero Level 2 Batch 8 Assignment 1

## Repository Overview

This assignment focuses on practicing fundamental and advanced typescript concepts through practical coding exercises and technical blog writing.

The coding exercises cover functions, default parameters, union types, type narrowing, tuples, generics, interfaces, classes, inheritance, and asynchronous programming with error handling.

Additionally, two technical blog posts explain important typescript concepts:

<ol>
<li> Type vs Interface: Explains their core differences, features, and when to use each.</li>
<li>Type Narrowing: Explains type narrowing with practical examples using typeof, instanceof, and the in operator.</li>
</ol>

The main objective is to strengthen typescript knowledge, improve problem-solving skills, and understand how to write clean, reusable, and type-safe code.

- **`solutions.ts`** — typescript exercises covering functions, default parameters, union types, type narrowing, tuples, generics, interfaces, classes, inheritance, and asynchronous error handling.
- **`type-vs-interface.md`** — Explains the differences between typescript `type` aliases and `interface`, with examples and guidance on when to use each.
- **`type-narrowing.md`** — Introduces type narrowing with practical examples using `typeof`, `instanceof`, and the `in` operator.
